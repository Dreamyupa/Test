# OneThing

A personal focus app. Reduce decisions, don't add them.

## Stack

- React + Vite + TypeScript, Tailwind CSS v4
- PWA (installable, mobile-first)
- Persistence: `localStorage` only (Phase 1 — no backend/auth)
- UI language: Thai

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
